Agent Exposure Check

Paste an agent or MCP config. See what it can reach, what it can leak and what to block first.

No account. No upload. No tracking. No subscription.

CyberChef shows what a blob of data contains. This shows what an agent is allowed to do with it. It runs in this tab and keeps nothing.

Starter policy


    
Put this outside the agent. Check it with your own team before use. It blocks first and asks for the rest.


    
Evidence chain

    

    
Local hash chain. Tamper evident, not tamper proof. If someone controls the whole page, they can rewrite the chain.


    
  


  

    
Why this exists

    
CyberChef is good at showing bytes. A business also needs to know which tool can delete a file, which server has no login and which instruction lives inside a document an agent will read. This tool names those things in plain English before they become an incident.


    
What this does not do

    
    
      
  • It does not connect to your systems.
    • 
      
  • It does not test an exploit or run a command.
    • 
      
  • It does not decide what is safe for your organisation.
    • 
      
  • It does not keep your config after you close the tab.
